# MCphone Ultra 資源庫

MCphone Ultra mod 的小說與應用下載站。

## 網站

https://ryanwu047-wq.github.io/mcphone-ultra-store/

## 如何上傳

### 上傳小說
1. 進入 `novels/` 資料夾
2. 點「Add file」→「Upload files」
3. 上傳 .txt 檔案
4. 點「Commit changes」

### 上傳應用
1. 進入 `apps/` 資料夾
2. 點「Add file」→「Upload files」
3. 上傳 .jar 或 .zip 檔案
4. 點「Commit changes」

## 檔案規範

- 小說：.txt 格式，建議 UTF-8 編碼
- 應用：.jar 或 .zip 格式，需包含有效的 SPI 清單

## 技術

- GitHub Pages 託管
- GitHub API 動態列出檔案
- 純靜態網站，無後端
